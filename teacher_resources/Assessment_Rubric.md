# Dataset Storytelling Assessment Rubric

| Criteria | Novice (1 pt) | Developing (2 pts) | Proficient (3 pts) | Advanced (4 pts) |
| :--- | :--- | :--- | :--- | :--- |
| **Data Hygiene (25%)** | Uncleaned data with unhandled NaNs. | Basic cleaning performed; formatting inconsistent. | Clean dataset with appropriate data types and handled NaNs. | Exceptional data prep, documented pipeline, cached loading. |
| **Chart Choice (25%)** | Inappropriate chart types used. | Chart types appropriate but misconfigured. | Clear, accurate charts with appropriate encodings. | Highly intuitive visual story with log scales, hover details, and color harmony. |
| **Narrative Clarity (25%)** | No conclusion or summary provided. | Basic description of plot without depth. | Clear narrative connecting findings to initial question. | Compelling data story with synthesis, limitations, and actionable recommendations. |
| **Streamlit App (25%)** | Code fails to execute or crashes. | Basic layout without filters or formatting. | Functional dashboard with interactive filters and sidebar layout. | Production-grade app with modular functions, metric cards, and clean UI styling. |
